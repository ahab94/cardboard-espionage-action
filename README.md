Check: bash checks/verify.sh

## Godot Sandbox

Install Godot 4: `brew install --cask godot` (provides the `godot` command).

- Open: launch Godot, click Import, select `project.godot` in this folder.
- Run: press F5 in the editor, or `godot --path .` from the terminal. Move the square with the arrow keys.
- Smoke test: `bash checks/verify.sh`
